## 大問2 正しい形を選ぶ(20点:各2点)★☆☆〜★★☆

( )に入る最も適切なものを①〜④から一つ選び、番号で答えなさい。

**2-1.** 지금 제가 ( ) 식당은 아주 맛있어요.
　① 간　② 갈　③ 가는　④ 가ㄴ

**2-2.** 어제 제가 ( ) 김치는 아주 맛있었어요.
　① 먹은　② 먹는　③ 먹을　④ 먹ㄴ

**2-3.** 내일 제가 ( ) 사람은 선생님이에요.
　① 만나는　② 만난　③ 만나을　④ 만날

**2-4.** 저는 어제 아주 ( ) 산에 갔어요.
　① 높는　② 높은　③ 높을　④ 높ㄴ

**2-5.** 저는 ( ) 음식을 자주 먹어요.
　① 싸는　② 싸ㄴ　③ 싼　④ 싸은

**2-6.** 어제 제가 ( ) 이야기는 아주 재미있었어요.
　① 쓴　② 쓰는　③ 쓸　④ 쓰은

**2-7.** 지금 이 도시에 ( ) 사람은 많아요.
　① 살는　② 산　③ 살　④ 사는

**2-8.** 이 식당에는 ( ) 김치가 있어요.
　① 맛있은　② 맛있는　③ 맛있을　④ 맛있ㄴ

**2-9.** 저는 어제 회사원( ) 친구를 만났어요.
　① 인　② 이는　③ 일　④ 이은

**2-10.** 저는 ( ) 사과를 먹었어요.
　① 빨갛은　② 빨갈　③ 빨간　④ 빨갛는

## 大問3 ( )内の語を連体形に(20点:各2点)★★☆

( )内の語を文に合う連体形に変えて書きなさい。解答は変えた1語のみを書くこと。

**3-1.** 지금 이 식당에서 (일하다) 사람은 제 친구예요.

**3-2.** 지금 학교에서 (공부하다) 학생은 많아요.

**3-3.** 어제 우리 집에 (오다) 친구는 선생님이에요.

**3-4.** 어제 제가 (찾다) 책은 이 책이에요.

**3-5.** 내일 제가 (입다) 옷은 이 옷이에요.

**3-6.** 이것은 아주 (비싸다) 가방이에요.

**3-7.** 저는 (조용하다) 도시에서 살아요.

**3-8.** 날씨가 (좋다) 때 우리는 같이 학교에 가요.

**3-9.** 이 도시에는 사람이 (없다) 길이 많아요.

**3-10.** 저는 학생이 (아니다) 사람이에요.

例) 많다〈形容詞・現在〉＋ 사람 → 많은 사람

## 大問5 日本語→韓国語(20点:各4点)★★☆

日本語の意味になるように、〔 〕内の語句を与えられた順にすべて使って韓国語の文を書きなさい。用言(基本形で示した語)は適切な形に変えること。

例) これは私たちが学校で習う歌です。〔이것은 / 우리가 / 학교에서 / 배우다 / 노래예요〕
　→ 이것은 우리가 학교에서 배우는 노래예요.

**5-1.** 昨日私が飲んだコーヒーは高かったです。
　〔어제 / 제가 / 마시다 / 커피는 / 비쌌어요〕

**5-2.** 明日私たちが見る映画は面白いです。
　〔내일 / 우리가 / 보다 / 영화는 / 재미있어요〕

**5-3.** これはとても辛いキムチです。
　〔이것은 / 아주 / 맵다 / 김치예요〕

**5-4.** 私は面白い映画を見ました。
　〔저는 / 재미있다 / 영화를 / 봤어요〕

**5-5.** この人は私が知っている先生です。
　〔이 사람은 / 제가 / 알다 / 선생님이에요〕
