## 大問2 正しい形を選ぶ(20点:各2点)★☆☆〜★★☆

( )に入る最も適切なものを①〜④から一つ選び、番号で答えなさい。

**2-1.** 지금 제가 ( ) 노래는 아주 어려워요.
　① 배운　② 배우는　③ 배울　④ 배우ㄴ

**2-2.** 저는 ( ) 케이크를 자주 먹어요.
　① 다는　② 달은　③ 달는　④ 단

**2-3.** 오늘은 ( ) 날씨예요.
　① 덥는　② 덥은　③ 더운　④ 더울

**2-4.** 어제 저를 ( ) 친구에게 커피를 샀어요.
　① 도운　② 돕은　③ 돕는　④ 도울

**2-5.** 그 사람은 ( ) 사람이에요?
　① 어떻은　② 어떤　③ 어떻는　④ 어떨

**2-6.** 어제 제가 ( ) 노래는 아주 좋았어요.
　① 듣은　② 들는　③ 들은　④ 들ㄴ

**2-7.** 저는 ( ) 커피를 자주 마셔요.
　① 비싸는　② 비싸ㄴ　③ 비쌀　④ 비싼

**2-8.** 이 사람은 학생이 ( ) 선생님이에요.
　① 아닌　② 아니는　③ 아니은　④ 아닐

**2-9.** 어제 제가 ( ) 노래는 아주 어려웠어요.
　① 불른　② 부른　③ 부를　④ 부르는

**2-10.** 이것은 제가 ( ) 빵이에요. (食べかけのパン)
　① 먹는　② 먹은　③ 먹던　④ 먹을

## 大問3 ( )内の語を連体形に(20点:各2点)★★☆

( )内の語を文に合う連体形に変えて書きなさい。解答は変えた1語のみを書くこと。

**3-1.** 여기는 (싸다) 가방이 많아요.

**3-2.** 저는 (깨끗하다) 방에서 공부해요.

**3-3.** 저는 학교에서 (가깝다) 집에서 살아요.

**3-4.** 이것은 아주 (쉽다) 문제예요.

**3-5.** 음식이 (맵다) 때 우리는 물을 마셔요.

**3-6.** 저는 길을 (걷다) 사람을 봤어요.

**3-7.** 내일 제가 (듣다) 노래는 이 노래예요.

**3-8.** 이 집을 (짓다) 사람은 제 친구예요.

**3-9.** 저는 학생(이다) 친구가 있어요.

**3-10.** 이 도시에는 (맛있다) 식당이 많아요.

**4-6.** 받다〈動詞・過去〉＋ 책 → 答:________ 책

**4-7.** 듣다〈動詞・現在〉＋ 음악 → 答:________ 음악

**4-8.** 짓다〈動詞・現在〉＋ 집 → 答:________ 집

## 大問5 日本語→韓国語(20点:各4点)★★☆

日本語の意味になるように、〔 〕内の語句を与えられた順にすべて使って韓国語の文を書きなさい。用言(基本形で示した語)は適切な形に変えること。

例) これは私たちが学校で習う歌です。〔이것은 / 우리가 / 학교에서 / 배우다 / 노래예요〕
　→ 이것은 우리가 학교에서 배우는 노래예요.

**5-1.** これは私がよく読んでいた本です。(※ `-던` を使うこと)
　〔이것은 / 제가 / 자주 / 읽다 / 책이에요〕

**5-2.** 私にはとてもかわいい友達がいます。
　〔저는 / 아주 / 귀엽다 / 친구가 / 있어요〕

**5-3.** 私は黄色い服を着ました。
　〔저는 / 노랗다 / 옷을 / 입었어요〕

**5-4.** 昨日私が歩いた道は長かったです。
　〔어제 / 제가 / 걷다 / 길은 / 길었어요〕

**5-5.** これは私が今住んでいる家です。
　〔이것은 / 지금 / 제가 / 살다 / 집이에요〕
