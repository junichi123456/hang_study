# 韓国語 文法問題集「連体形」 第5回(set05)

| 項目 | 内容 |
|---|---|
| 範囲 | 到達度確認(連体形+`-는데/-(으)ㄴ데`・`-(으)면서` の総合)。重点: ㅎ・ㄷ・르変則、`-던`、`-(으)면서` |
| 満点 | 100点 |
| 所要時間の目安 | 40分 |
| 提出方法 | `problems/set05/answer_sheet.md` の各番号の後ろに解答を記入して提出してください(詳細は末尾「提出方法」)。 |

> **第4回の振り返りヒント(例の語は今回の問題には出ません)**:
> | 項目 | 規則 | 例 |
> |---|---|---|
> | ㅎ変則 | ㅎ**も**으**も**落ちる(`-던` の前では不変) | 이렇다→**이런** / **이런데** / 이렇던 |
> | ㄷ変則 | `-는`・`-는데`・`-던` では不変。`으` で始まる語尾(`-은/-을/-으면서`)の前で ㄷ→ㄹ | 싣다→싣는 / **실은** / **실을** / **실으면서** / 싣던 |
> | ㄹ語幹 | 連体形・`-는데` ではㄹ脱落。**`-(으)면서`・`-던` ではㄹが残る**(`으` は付かない) | 팔다→파는 / 판 / 파는데 / **팔면서** / **팔던** |
> | ㅅ変則 | `으` の前でㅅ脱落(`으`は残る) | 낫다→**나은** / **나을** / 낫는 / 낫던 |
> | 르変則 | 連体形・`-는데`・`-(으)면서`・`-던` では不変。`-았/었던` では 르→ㄹ라/ㄹ러 | 빠르다→빠른 / 빠르던 / **빨랐던** |
> | `-던` | 語幹に**直接**付く(分かち書きしない。連体形に던を足さない) | 쓰다→쓰던(쓴 던✕) |
> | 母音語幹の形容詞 | `-ㄴ` だけ(`으`は付かない) | 예쁘다→예쁜 / 예쁜데 |

> **語彙補足について**: 各大問の直後にその大問で使った語を載せています(既出語も含む)。同じ回の中で一度載せた語は再掲しません。**過去4回以上出題された語は、第5回から補足を省略しています**(`vocab/cumulative.md` の出題回を参照)。

## 大問2 正しい形を選ぶ(20点:各2点)★★☆

( )に入る最も適切なものを①〜④から一つ選び、番号で答えなさい。(　)内の日本語は文の意味のヒントです。

**2-1.** 이 음식은 ( ) 물을 마셔요.
　① 짜는데　② 짠데　③ 짜은데　④ 짤데

**2-2.** 제 친구는 의사( ) 일이 아주 많아요.
　① 인데　② 은데　③ 는데　④ 일데

**2-3.** 미국에 ( ) 영어를 배웠어요.
　① 살으면서　② 사면서　③ 사으면서　④ 살면서

**2-4.** 음악을 ( ) 공부해요.
　① 듣으면서　② 들면서　③ 들으면서　④ 듣면서

**2-5.** 저는 ( ) 옷을 샀어요.
　① 하얗은　② 하얀　③ 하야은　④ 하얗는

**2-6.** 할아버지가 ( ) 집은 지금도 있어요.
　① 진　② 짓은　③ 지은　④ 짓는

**2-7.** 전에는 ( ) 이야기가 지금은 같아요. (以前は違っていた話が今は同じです)
　① 달랐던　② 달렀던　③ 다르았던　④ 다른던

**2-8.** 제가 자주 ( ) 책은 이 책이에요. (よく読んでいた本)
　① 읽는 던　② 읽은　③ 읽을　④ 읽던

**2-9.** 내일 ( ) 일이 많아요. (明日やるべきことが多いです)
　① 한　② 할　③ 하는　④ 하던

**2-10.** 죄송합니다. 지금 안 ( ).
　① 계신데요　② 계시은데요　③ 계시는데요　④ 계실데요

## 大問3 ( )内の語を指定の形に(20点:各2点)★★☆

( )内の語を、文に合う形に変えて書きなさい。「(基本形 / -(으)ㄴ데)」のように語尾が指定されているものは、その語尾を使うこと。語尾の指定がないものは連体形にすること。解答は変えた1語のみを書くこと(名詞に付く「이다」は、이다を変えた形だけでもよい)。

**3-1.** 저는 (노랗다) 옷을 입었어요.

**3-2.** 제가 자주 (걷다 / -던) 길은 지금도 있어요.

**3-3.** 전에 학생(이다 / -었던) 친구가 지금은 선생님이에요.

**3-4.** 저는 (덥다) 때 물을 자주 마셔요.

**3-5.** 어제 제가 만난 친구가 (살다) 집은 아주 커요.

**3-6.** 날씨가 (좋다 / -(으)ㄴ데) 같이 공원에 가요.

**3-7.** 빵을 (굽다 / -(으)면서) 노래를 들어요.

**3-8.** 한국어를 (배우다 / -았는데/-었는데) 아직 한국에 안 갔어요.

**3-9.** 내년에 아버지가 (짓다) 집에서 살고 싶어요.

**3-10.** 내일 제가 (듣다) 노래는 이 노래예요.

## 大問5 日本語→韓国語(20点:各4点)★★☆

(採点: 指定の形が正しければ3点、文全体が正しく〔 〕内の語をすべて使っていれば+1点。)

例) これは韓国語の本ですが、面白いです。(※ `-(으)ㄴ데`)　〔한국어 / 책 / 재미있다〕
