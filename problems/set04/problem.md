# 韓国語 文法問題集「連体形」 第4回(set04)〈リニューアル版〉

| 項目 | 内容 |
|---|---|
| 範囲 | 連体形の重点復習(ㄷ・ㅅ・ㅂ変則)+ 教科書第12課の `-는데/-(으)ㄴ데`・`-았는데/-었는데`・`-(으)면서` |
| 満点 | 100点 |
| 所要時間の目安 | 40分 |
| 提出方法 | `problems/set04/answer_sheet.md` の各番号の後ろに解答を記入して提出してください(詳細は末尾「提出方法」)。 |

> **今回のねらい**: 連体形の `-는` / `-(으)ㄴ` の使い分け(動詞・存在詞は `-는`、形容詞・이다は `-(으)ㄴ`)は、接続語尾 **`-는데` / `-(으)ㄴ데`** でもまったく同じ規則です。さらに、**`-(으)면서`** では ㄷ変則・ㅂ変則・ㅅ変則・ㄹ語幹が連体形と同じように変化します。教科書(第12課)で学んだ形を、連体形の知識と結びつけて確認しましょう。

> **ヒント(例の語は今回の問題には出ません)**:
> | 形 | 規則 | 例 |
> |---|---|---|
> | `-는데` | 動詞・存在詞(있다/없다/계시다)。ㄹ語幹はㄹ脱落 | 먹다→먹는데 / 없다→없는데 / 놀다→노는데 |
> | `-(으)ㄴ데` | 形容詞・이다(指定詞)。ㄹ語幹はㄹ脱落、ㅂ変則は우 | 작다→작은데 / 가수+이다→가수인데(母音で終わる名詞は 이 を省略して ○ㄴ데 の形も可) |
> | `-았는데/-었는데` | 品詞を問わず過去は `-았는데/-었는데`(이다は `-였는데/-이었는데`) | 먹다→먹었는데 / 작다→작았는데 |
> | `-(으)면서` | 〜しながら。ㄹ語幹はㄹ脱落**しない**、ㄷ・ㅂ・ㅅ変則は `으` の前で変化 | 걷다→걸으면서 / 놀다→놀면서 |
> - 後ろの文が勧誘・命令のときは、`-는데/-(으)ㄴ데` は「理由」を表します。
> - `-고 싶다` の 싶다 は**補助形容詞**(形容詞扱い)です。`-는데` か `-(으)ㄴ데` のどちらが付くか考えましょう。

> **語彙補足について**: 各大問の直後にその大問で使った語を載せています(既出語も含む)。同じ回の中で一度載せた語は再掲しません。

## 大問3 ( )内の語を指定の形に(20点:各2点)★★☆

( )内の語を、文に合う形に変えて書きなさい。「(基本形 / -(으)ㄴ데요)」のように語尾が指定されているものは、その語尾を使うこと。語尾の指定がないものは連体形にすること。解答は変えた1語のみを書くこと(名詞に付く「이다」は、이다を変えた形だけでもよい)。

**3-1.** A: 한국 분이세요?　B: 네, 저는 한국 사람(이다 / -(으)ㄴ데요).

**3-2.** A: 일본 분이세요?　B: 아뇨, 저는 한국 사람이 (아니다 / -(으)ㄴ데요).

**3-3.** 이 드라마는 (재미있다 / -는데) 왜 안 봐요?

**3-4.** 이거 좀 (짜다 / -(으)ㄴ데요).

**3-5.** 내일 친구를 (만나다 / -는데) 같이 가요.

**3-6.** 노래를 (부르다 / -(으)면서) 공부해요.

**3-7.** 음식을 (만들다 / -(으)면서) 노래를 들어요.

**3-8.** 어제 영화를 (보다 / -았는데/-었는데) 아주 재미있었어요.

**3-9.** 내년에 아버지가 (짓다) 집에서 살고 싶어요.

**3-10.** 제가 (듣다) 노래는 아주 좋았어요.

## 大問5 日本語→韓国語(20点:各4点)★★☆

日本語の意味になるように、〔 〕内の語句を**与えられた順に**使って韓国語の文を書きなさい。語群には**助詞(은/는・이/가・을/를 など)が付いていません。適切な助詞を補う**こと。用言(基本形で示した語)は指定の形にし、文末の語(〜어요/〜아요/〜세요 など)は与えられたとおり書くこと。
(採点: 指定の形が正しければ3点、文全体の助詞・語順・語句が正しければ+1点。助詞の使い分けなどで複数の正解があり得る場合は、どれも正解とします。)

例) これは韓国語の本ですが、面白いです。(※ `-(으)ㄴ데`)　〔이것 / 한국어 / 책 / 재미있어요〕
　→ 이것은 한국어 책인데 재미있어요.

**5-1.** 運動をしているのですが、とても大変です。(※ `-는데/-(으)ㄴ데`)
　〔운동 / 하다 / 너무 / 힘들어요〕

**5-2.** 旅行に行きたいのですが、お金がありません。(※ `-는데/-(으)ㄴ데`)
　〔여행 / 가고 싶다 / 돈 / 없어요〕

**5-3.** 顔は知っているけれど、名前は分かりません。(※ `-는데/-(으)ㄴ데`)
　〔얼굴 / 알다 / 이름 / 모르겠어요〕

**5-4.** 音楽でも聞きながら勉強してください。(※ `-(으)면서`)
　〔음악이라도 / 듣다 / 공부하세요〕

**5-5.** 姉は教師なのですが、仕事がとても忙しいです。(※ `-(으)ㄴ데`)
　〔언니 / 교사 / 일 / 아주 / 바빠요〕
