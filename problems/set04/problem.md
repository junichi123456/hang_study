| 満点 | 100点 |
| 所要時間の目安 | 40分 |
| 提出方法 | `problems/set04/answer_sheet.md` の各番号の後ろに解答を記入して提出してください(詳細は末尾「提出方法」)。 |

> **第3回の振り返りヒント(変則活用の「変え方」。例の語は今回の問題には出ません)**:
> | 種別 | 規則 | 例 |
> |---|---|---|
> | ㄷ変則 | ㄷ→ㄹ(`으`で始まる語尾の前のみ)。`-는`・`-던` の前では不変 | 싣다 → **실은** / **실을** / 싣는 / 싣던 |
> | ㅅ変則 | ㅅが脱落(`으`は**残る**)。`-는`・`-던` の前では不変 | 낫다 → **나은** / **나을** / 낫는 / 낫던 |
> | ㅎ変則 | ㅎが脱落(`으`は**付かない**)。`-던` の前では不変 | 하얗다 → **하얀** / **하얄** / 하얗던 |
> | ㅂ変則 | ㅂ→우+ㄴ/ㄹ(形容詞に `-는` は付かない)。`-던` の前では不変 | 쉽다 → **쉬운** / **쉬울** / 쉽던 |
> | 르変則 | `-는/-ㄴ/-ㄹ/-던` の前では**不変**。`-았/었던` では 르→ㄹ라/ㄹ러 | 빠르다 → 빠른 / 빠르던 / **빨랐던** |
> - `이다` の回想(-었던): 名詞の末尾が**子音か母音か**で形が変わります(第3回の採点結果を参照)。

> **語彙補足について**: 各大問の直後にその大問で使った語を載せています(既出語も含む)。同じ回の中で一度載せた語は再掲しません。[熟]=慣用句(意味のまとまりで訳しています)。

## 大問3 ( )内の語を連体形に(20点:各2点)★★☆

( )内の語を文に合う連体形に変えて書きなさい。解答は変えた1語のみを書くこと。「(基本形 / -던)」のように語尾が指定されているものは、その語尾を使うこと。名詞に付く「이다」は、이다を変えた形(例: ○○였던)だけを書いてもよい。

**3-1.** 지금 음악을 (듣다) 사람은 제 친구예요.

**3-2.** 어제 제가 (걷다) 길은 아주 길었어요.

**3-3.** 아버지가 (짓다) 식당은 지금도 있어요.

**3-4.** 전에 회사원(이다 / -었던) 친구가 지금은 선생님이에요.

**3-5.** 전에 의사(이다 / -었던) 친구가 지금은 회사원이에요.

**3-6.** 어제 제가 만난 친구는 (춥다) 날씨에 커피를 자주 마셔요.

**3-7.** 저는 (덥다) 때 물을 자주 마셔요.

**3-8.** 제 친구는 손이 (크다) 사람이에요. (気前のいい人)

**3-9.** 주말에 제가 (먹다) 음식은 김치예요.

**3-10.** 작년에 제가 (모르다 / -았던) 사람이 지금은 친구예요.

## 大問5 日本語→韓国語(20点:各4点)★★☆

日本語の意味になるように、〔 〕内の語句を**与えられた順に**使って韓国語の文を書きなさい。語群には**助詞(은/는・이/가・을/를・에서 など)が付いていません。適切な助詞を補う**こと。用言(基本形で示した語)は適切な連体形にし、文末の語(〜예요/〜이에요/〜아요 など)は与えられたとおり書くこと。
(採点: 連体形が正しければ3点、文全体の助詞・語順・語句が正しければ+1点。助詞の使い分けで複数の正解があり得る場合は、どれも正解とします。)

例) これは私たちが学校で習う歌です。〔이것 / 우리 / 학교 / 배우다 / 노래예요〕
　→ 이것은 우리가 학교에서 배우는 노래예요.

**5-1.** これは私が昨日聞いた話です。
　〔이것 / 제가 / 어제 / 듣다 / 이야기예요〕

**5-2.** これは父が建てた家です。
　〔이것 / 아버지 / 짓다 / 집이에요〕

**5-3.** これは私が気に入っている服です。
　〔이것 / 제가 / 마음에 들다 / 옷이에요〕

**5-4.** これは私が昔住んでいた家です。(※ `-던` を使うこと)
　〔이것 / 제가 / 살다 / 집이에요〕

**5-5.** とても難しい問題が多いです。
　〔아주 / 어렵다 / 문제 / 많아요〕
