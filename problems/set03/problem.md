| 範囲 | 回想 `-던` と `-았던/-었던`/時制の読み取り/ㄷ・ㅅ変則と規則活用の見分け |

> **第2回の振り返りヒント**:
> - 時を表す語(지금・어제・내일・매일 など)や述語の時制を先に見て、`-는`/`-(으)ㄴ`/`-(으)ㄹ` を決める。
> - ㄷ変則・ㅅ変則は、現在 `-는` では語幹が変わらず、過去 `-은`・未来 `-을` で変わる。좋다・받다・닫다・놓다などは変則ではない。
> - **回想 `-던`**: 「〜していた(未完了・繰り返し)」。語幹にそのまま付く(分かち書きしない。ㄹ脱落もしない)。
> - **`-았던/-었던`**: 「〜した(完了した一度の出来事の回想)」。

> **語彙補足について**: 第3回から、各大問の直後にその大問で使った語の補足(既出語を含む)を載せています。同じ回の中で一度載せた語は再掲しません。

## 大問2 正しい形を選ぶ(20点:各2点)★★☆

( )に入る最も適切なものを①〜④から一つ選び、番号で答えなさい。(　)内の日本語は文の意味のヒントです。

**2-1.** 내일 제가 ( ) 가방은 이 가방이에요.
　① 산　② 사는　③ 살　④ 사던

**2-2.** 제가 매일 ( ) 커피는 아주 맛있어요.
　① 마신　② 마시는　③ 마실　④ 마시은

**2-3.** 이것은 제가 어제 ( ) 책이에요. (読みかけの本)
　① 읽는　② 읽은　③ 읽을　④ 읽던

**2-4.** 작년에 제가 ( ) 친구는 지금 여기에 없어요. (去年一度会った友達)
　① 만나는　② 만나던　③ 만났던　④ 만날

**2-5.** 오늘 ( ) 일이 많아요. (今日やるべきことが多いです)
　① 한　② 하는　③ 하던　④ 할

**2-6.** 어제 우리가 ( ) 길은 아주 길었어요.
　① 걷은　② 걷는　③ 걸은　④ 걸을

**2-7.** 제가 ( ) 집은 지금 없어요. (昔住んでいた家)
　① 살던　② 사던　③ 사는　④ 살는

**2-8.** 제가 자주 ( ) 노래는 이 노래예요. (よく歌っていた歌)
　① 부르던　② 부른　③ 부르는　④ 불르던

**2-9.** 이것은 지금 제가 ( ) 음식이에요. (今作っている料理)
　① 만든　② 만드는　③ 만들　④ 만들는

**2-10.** 저는 ( ) 방에서 살아요.
　① 크는　② 큰　③ 클　④ 크ㄴ

## 大問5 日本語→韓国語(20点:各4点)★★☆

日本語の意味になるように、〔 〕内の語句を与えられた順にすべて使って韓国語の文を書きなさい。用言(基本形で示した語)は適切な形に変えること。

例) これは私たちが学校で習う歌です。〔이것은 / 우리가 / 학교에서 / 배우다 / 노래예요〕
　→ 이것은 우리가 학교에서 배우는 노래예요.

**5-1.** ここは去年私が行った所です。(※ `-았던/-었던` を使うこと)
　〔이곳은 / 작년에 / 제가 / 가다 / 곳이에요〕

**5-2.** これは私がよく飲んでいたコーヒーです。(※ `-던` を使うこと)
　〔이것은 / 제가 / 자주 / 마시다 / 커피예요〕

**5-3.** 昨日私が聞いた話は面白かったです。
　〔어제 / 제가 / 듣다 / 이야기는 / 재미있었어요〕

**5-4.** 私は学校から近い家に住んでいます。
　〔저는 / 학교에서 / 가깝다 / 집에서 / 살아요〕

**5-5.** この人は学生ではない会社員です。
　〔이 사람은 / 학생이 / 아니다 / 회사원이에요〕
