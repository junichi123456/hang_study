## 1. 目的・スコープ・ワークフロー・ディレクトリ構成

### 1.1 目的
- 韓国語の**動詞・形容詞・存在詞・指定詞(이다/아니다)の連体形**を中心とした活用・変形を、反復演習で定着させる。
- ゴール: 第7章の「習得到達基準」を満たすこと(連体形をある程度自力で正しく作れ、文中で時制・品詞に応じて使い分けられる状態)。

### 1.2 スコープ
- 対象: 連体形語尾 `-는` / `-(으)ㄴ` / `-(으)ㄹ` / `-던` / `-았던・-었던`、および変則活用(ㄹ語幹・ㅂ・ㅎ・ㄷ・ㅅ・르)との組み合わせ。
- 対象外: 連体形以外の文法(敬語体系、引用、連結語尾の網羅等)は**出題の主眼にしない**。ただし文末(-아요/어요体、-입니다)は問題文中に普通に現れてよい。
- 使用語彙: 基本的な動詞・形容詞・名詞に限る(第4章)。

### 1.3 リポジトリ運用方針
- **分野ごとにブランチを分ける**。命名規則は第9章。本ブランチは「文法:連体形」専用。
- `main` へのマージは行わない(ユーザーの指示がない限り)。

### 1.4 ワークフロー(1サイクル = 1セット)

## 2. 連体形の文法体系

### 2.1 総覧表

| 品詞 | 現在 | 過去(完了) | 過去回想 | 未来・予定・推量 |
|---|---|---|---|---|
| 動詞 | `-는` | `-(으)ㄴ` | `-던` / `-았던・-었던` | `-(으)ㄹ` |
| 形容詞 | `-(으)ㄴ` | (なし。過去は回想形で表す) | `-던` / `-았던・-었던` | `-(으)ㄹ` |
| 存在詞(있다・없다 系) | `-는` | (`-(으)ㄴ` は通常使わない) | `-던` / `-었던` | `-(으)ㄹ` |
| 이다 | `인` | (なし) | `이던` / `이었던`(母音終わり名詞は `였던` も可) | `일` |
| 아니다 | `아닌` | (なし) | `아니던` / `아니었던` | `아닐` |

- 媒介母音 `으` の規則: 語幹が**子音で終わる**(ㄹを除く)とき `-은` / `-을`、**母音で終わる**とき `-ㄴ` / `-ㄹ`。
  - 例: 먹다→먹은・먹을、읽다→읽은・읽을 / 가다→간・갈、보다→본・볼、마시다→마신・마실
- 하다 用言: 動詞の 공부하다→공부하는・공부한・공부할、形容詞の 조용하다→조용한・조용할。
  - `-하다` が付いても品詞で語尾が変わる(좋아하다 は**動詞**: 좋아하는 / 깨끗하다 は**形容詞**: 깨끗한)。

### 2.2 動詞
1. **現在 `-는`**: 語幹にそのまま付く(媒介母音なし)。가는, 먹는, 읽는, 공부하는
   - **ㄹ語幹はㄹ脱落**: 살다→사는、만들다→만드는、알다→아는、팔다→파는、놀다→노는
2. **過去 `-(으)ㄴ`**: 完了した動作。어제 읽은 책(昨日読んだ本)、간 곳(行った所)
   - **ㄹ語幹はㄹ脱落して `-ㄴ`**: 살다→산、만들다→만든、알다→안、팔다→판
   - 注意: 입다・앉다・결혼하다 などは過去形が「結果状態」を表すことがある(입은 옷 = 着ている服)。**時制選択を問う小問ではこの種の動詞を使わない**(第8章)。
3. **未来・予定・推量 `-(으)ㄹ`**: 내일 만날 사람(明日会う人)、먹을 음식(食べる予定の食べ物)
   - **ㄹ語幹はそのまま `ㄹ` が重ならない**: 살다→살、만들다→만들(✕살을、✕만들을)
   - 時制性の薄い用法: `-(으)ㄹ 때`(〜するとき)、`할 일`(するべきこと)、`먹을 것`(食べ物)。
4. **過去回想 `-던`**: 過去に繰り返していた/継続していた/途中だった動作の回想。자주 가던 식당(よく行っていた店)、먹던 빵(食べかけのパン)
   - ㄹ語幹は**脱落しない**: 살던、만들던
5. **`-았던/-었던`**: 過去に完了した(一回的な)出来事の回想。작년에 갔던 곳(去年行った所)。
   - `-던` との違い: `-던` は「未完了・反復・継続」、`-았/었던` は「完了・断絶(今はそうではない/一度きり)」の含みが強い。動詞の `-(으)ㄴ` は単なる完了、`-았/었던` は回想の含みを伴う。

### 2.3 存在詞(있다・없다 とその合成語)
- 現在は**動詞と同じく `-는`**: 있는、없는、맛있는、맛없는、재미있는、재미없는
- ✕맛있은、✕재미있은 は誤り(現在の意味では使わない)。
- 回想: 있던/있었던、없던/없었던。未来・推量: 있을、없을。

### 2.4 形容詞
1. **現在 `-(으)ㄴ`**: 큰, 작은, 좋은, 많은, 바쁜, 깨끗한
   - **形容詞に `-는` は付かない**(✕크는、✕좋는)。動詞との取り違えは典型的誤り。
   - **ㄹ語幹はㄹ脱落**: 길다→긴、달다→단、멀다→먼
2. **過去回想 `-던` / `-았던・-었던`**: 어렸을 때 작던 방 / 작았던 방(かつて小さかった部屋)。形容詞では両者の差は小さく、`-았/었던` の方が「今はそうではない」含みがやや強い。
3. **未来・推量 `-(으)ㄹ`**: 추울 때(寒いとき)、클 것 같다(大きそうだ)。ㄹ語幹: 길다→길。

### 2.5 이다 / 아니다(指定詞)
- 現在: 名詞+`인`(名詞の末尾が母音でも子音でも `인`): 학생인 친구、의사인 언니
- 推量・未来: 名詞+`일`: 학생일 때(学生のとき)
- 回想: 학생이던/학생이었던、의사이던/의사였던
- 아니다: 아닌、아닐、아니던/아니었던(例: 학생이 아닌 사람)

### 2.6 変則活用と連体形

| 種別 | 規則 | 現在(動詞 -는) | 過去/形容詞現在 -(으)ㄴ | -(으)ㄹ | -던 | 規則活用の紛らわしい語 |
|---|---|---|---|---|---|---|
| ㄹ語幹 | ㄴ・ㅂ・ㅅ・(오) の前でㄹ脱落 | 사는, 만드는 | 산, 만든 / 긴, 단 | 살, 만들, 길 | 살던, 길던(脱落なし) | ― |
| ㅂ変則 | 母音語尾の前で ㅂ→우(돕다・곱다 は 오) | 돕는, 굽는(変化なし) | 도운, 구운 / 추운, 더운, 쉬운, 어려운, 매운, 가까운 | 도울, 추울 | 돕던, 춥던 | 입다(입은)、잡다(잡은)、좁다(좁은)、씹다 |
| ㅎ変則(形容詞) | `-(으)ㄴ/ㄹ` の前で ㅎ と 으 が脱落 | (形容詞なので該当なし) | 그런, 어떤, 이런, 빨간, 하얀, 파란, 노란 | 그럴, 어떨, 빨갈 | 그렇던, 빨갛던 | 좋다(좋은)、놓다・넣다・낳다(動詞・規則) |
| ㄷ変則(動詞) | 母音語尾の前で ㄷ→ㄹ | 듣는, 걷는(変化なし) | 들은, 걸은 | 들을, 걸을 | 듣던, 걷던 | 받다(받은)、닫다(닫은)、믿다(믿은) |
| ㅅ変則 | 母音語尾の前で ㅅ脱落(으 は残る) | 짓는, 낫는(変化なし) | 지은, 나은 | 지을, 나을 | 짓던 | 웃다(웃은)、씻다(씻은)、벗다(벗은) |
| 르変則 | `-아/어` の前でのみ変化 ⇒ **連体形では変化しない** | 부르는, 모르는 | 부른, 모른 / 다른, 빠른 | 부를, 모를 | 부르던 | (回想 `-았/었던` では 불렀던, 몰랐던 と変化する) |
| 으語幹 | `-아/어` の前でのみ 으脱落 ⇒ 連体形では変化しない | 쓰는 | 쓴 / 바쁜, 아픈 | 쓸, 바쁠 | 쓰던 | (`-았/었던` では 썼던, 바빴던) |

- 要点: ㄷ・ㅅ・ㅂ変則は**媒介母音 `으` で始まる `-(으)ㄴ` / `-(으)ㄹ` の前で変化**し、`-는` / `-던` の前では変化しない。르・으語幹は**連体形では変化しない**(`-았/었던` を除く)。

### 2.7 -는 と -(으)ㄴ の使い分け(品詞判定)
- 「〜している/〜する」(現在)の連体形は、**動詞・存在詞 → `-는`**、**形容詞・이다 → `-(으)ㄴ` / `인`**。
- 同じ `-(으)ㄴ` でも、**動詞なら過去、形容詞なら現在**を表す(먹은 = 食べた / 작은 = 小さい)。

- 正答番号の分布: ①〜④がそれぞれ2〜3回。同一番号が3問連続しないこと。

## 4. 語彙ルール

### 4.1 基本ルール
1. 問題文・選択肢・語群で使う**内容語(動詞・形容詞・存在詞・名詞・副詞)は、4.3 の第1回語彙プールと 4.4 の機能語から選ぶ**。プール外の語を使う場合はプールに追加したうえで語彙表に載せる(第1回は原則プール内で完結させる)。
2. **初出語は必ずその回の `problem.md` 末尾「単語リスト」に、単元ごとに**、日本語訳・品詞・活用種別タグ・使用大問を付けて載せる。
3. 単語リストでは用言は**基本形のみ**を載せる(連体形は載せない=解答の漏洩防止)。
4. 第2回以降は**既出語の訳を再掲しない**。初出語のみ単語リストに載せ、全語は `vocab/cumulative.md` で累積管理する。
5. 単語リストの単元分類は「その語が主に練習される単元」とする:
   - 規則動詞・하다動詞 → 単元1 / 規則形容詞・ㄹ語幹形容詞 → 単元2 / ㄹ語幹動詞・変則用言・紛らわしい規則語 → 単元3 / 存在詞・이다・아니다 → 単元4 / 名詞・副詞・機能語 → 「共通語彙」節(単元とは別に最後に置く)。
   - 第1回で「共通語彙」節に載せる名詞・副詞は、その回で実際に使った語のみ。

### 4.2 活用種別タグ(語彙表の「活用種別」列で使う値)
`規則` / `하다` / `으語幹` / `ㄹ語幹` / `ㅂ変則` / `ㅂ規則` / `ㅎ変則` / `ㅎ規則` / `ㄷ変則` / `ㄷ規則` / `ㅅ変則` / `ㅅ規則` / `르変則` / `存在詞` / `指定詞` / `―`(名詞・副詞等)
- 「ㅂ規則」等の「〜規則」は、語幹末がその子音だが変則にならない語(紛らわしい語)に付ける。

## 6. 採点仕様

### 6.1 正誤基準
1. 比較前の正規化: 前後の空白除去、全角/半角スペースの同一視、文末の `.` `。` の有無は無視、NFC 正規化。
2. 大問1・3・4: **完全一致(正規化後)で正解**。部分点なし。許容解は解答キーに列挙したもののみ。
   - 大問4で被修飾名詞まで書いた場合(例: `만드는 사람`)も、連体形部分が正しければ正解とする。
3. 大問2: 番号のみで判定(①・1・"1番" はすべて 1 とみなす)。部分点なし。
4. 大問5(各4点): 部分点あり。
   - 連体形の部分が正しい: **3点**
   - 語群の語句をすべて与えられた順に使い、連体形以外の語句を改変していない: **1点**
   - 分かち書きの誤りは**減点しない**(結果ファイルで指摘し、誤答タグ T22 を記録する)。

### 7.2 タグ別の出題数調整

## 8. 品質基準

### 8.1 言語的正確性
1. すべての問題文は**韓国語として自然で文法的に正確**であること。標準語(서울말)・현행 맞춤법・띄어쓰기に従う。
2. 被修飾名詞と修飾語の組み合わせは意味的に自然であること(✕긴 날씨 のような組み合わせを作らない)。
3. 単語リストの訳は、その問題文中での意味に合わせる(多義語は使用された意味を先頭に書く)。
4. 第2章と矛盾する解答・解説を書かない。

### 8.2 一意性(1問1答)
1. 各小問の正解は**ただ1つ**に定まること。複数正解があり得る設計は出題段階で排除する。具体的には:
   - 時制を問う小問には、時を表す語(지금/어제/내일 等)または明確な文脈を必ず含める。
   - 入門回(set01〜02)の時制選択小問では、結果状態を表し得る動詞(입다・앉다・결혼하다 等)を使わない。
   - `-(으)ㄴ` と `-던` / `-았던` のどちらも成り立つ文を、set02 以前に作らない。
   - 大問5は語群・語順を固定し、変化させる用言を1つに限る(set01〜03)。
   - 大問2の誤選択肢が文脈次第で正解になり得ないこと。
2. 例外的に表記上の別解(例: 母音終わり名詞の `였던`/`이었던`)が避けられない場合は、解答キーの「許容解」に必ず列挙する。

### 8.3 自己検証(出題時に必須)
1. 解答キーの**下書き**を作成し、全小問について「正解」「出題タグ」「一意性の根拠」を確認する。
2. 配点合計=100、小問数=3.1 の表どおり、大問2の正答番号分布(①〜④ 各2〜3回)を確認する。
3. 使用語がすべて単語リストに載っていることを確認する(問題文中の内容語を1語ずつ照合)。
4. `problem.md`・`answer_sheet.md`・語彙表に**正解(連体形そのもの)が露出していない**ことを確認する。ただし大問4・5の例題の正解は除く(例題の語 많다・배우다 は採点対象の小問で使わないこと。問題文中の他の連体形が別の小問の正解と同一にならないことも確認する)。

### 8.4 解答の保管・提示の運用(確定)
- **出題時(段階A)**: 解答キーの下書きは**リポジトリの作業ツリー外**(セッションの作業用スクラッチ領域)に作成し、自己検証にのみ使う。`log/setNN/answers/` ディレクトリはリポジトリ内に作らない。チャットにも解答を書かない。`.gitignore` は使わない。
- **採点時(段階C)**: ユーザーの提出がコミットされた後、`problem.md` から解答キーを作成(下書きが残っていれば照合して差分を確認)し、`log/setNN/answers/answer_key.md` として**採点結果と同じコミット**でリポジトリに追加する。
  - 根拠: 8.2 により解答は問題文から一意に再導出できるため、セッションが変わって下書きが失われても採点の公正性は損なわれない。
- ユーザーが解答の先出しを明示的に求めた場合のみ、その指示に従う(その場合、該当回は弱点集計の対象外として `history.md` の備考に記録)。
